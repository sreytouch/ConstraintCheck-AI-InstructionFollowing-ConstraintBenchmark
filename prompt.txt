Build a complete beginner-friendly portfolio project called AI Constraint Following Benchmark.

Goal

Create an AI evaluation system that tests whether language models correctly follow prompts containing multiple instructions and constraints.

The project should demonstrate:

* instruction following
* constraint satisfaction
* human evaluation
* model comparison
* AI benchmarking
* preference data
* failure analysis
* reward-model concepts
* iterative improvement
* held-out evaluation
* reward hacking

The application should generate tasks containing multiple requirements, evaluate model responses against those requirements, identify exactly which constraints were violated, and calculate an overall instruction-following score.

Core Concept

Consider this prompt:

“Explain photosynthesis to a 10-year-old.

Requirements:

* use fewer than 80 words
* include one analogy
* do not use the word chlorophyll
* end with a question”

A response can be factually correct but still fail the task if it violates one of the explicit constraints.

The project should measure whether the AI satisfies all requested conditions.

Main Workflow

1. User selects or creates an evaluation task.
2. Task contains:
    * main request
    * multiple constraints
3. AI generates a response.
4. Application displays each constraint as a checklist.
5. Human evaluator determines which requirements were satisfied.
6. Application calculates compliance score.
7. Human provides rationale.
8. Evaluation is saved.
9. Analytics show common failure patterns.
10. Baseline and improved prompting strategies are compared.

Generation Strategies

Implement two strategies.

Baseline

Simple prompt containing the task.

Improved Constraint-Aware Strategy

Use a system instruction such as:

“You must satisfy every requirement in the user’s request.

Before answering:

1. Identify each explicit requirement.
2. Draft the answer.
3. Check the draft against every requirement.
4. Revise any violation.
5. Return only the final answer.

Do not mention your internal checklist.”

Allow comparing both strategies.
